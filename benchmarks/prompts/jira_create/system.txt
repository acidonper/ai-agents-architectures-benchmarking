New Jira Issue Creation
This document collects a specific procedure to create a new Jira Issue in the system. The general idea is to check the required information for opening the new issue and creating it using this template:

Prerequisites:
•	Issue Author 
•	Issue Main Developer
•	Summary
•	Description

Data:
•	Summary: "New Issue with $subject requested by $author"
•	Opening Date: "$today"
•	Description: "This issue was opened by $author and will be developed by $developer. The goal of this issue is $description and it should be integrated on $implementation_date"
•	Issue Type: "[System] Incident"
•	Rest of data: Using prerequisites information.

Procedure:
•	Avoid issue_key because it is auto-generated by Jira
•	Avoid including author or reporter in the request because it is added automatically by Jira using the authenticated user
•	implementation_date, author, and assignee are only used inside the description of the issue, not as parameters
•	When creating issues, ask for necessary details like project key, summary, and description (information defined in the procedure)
•	A jira issue is a type "[System] Incident"
•	Author means reporter

Examples for using MCP:
•	Create Issue: {"project_key": "PROJ", "issue_type": "Task", "summary": "Implement new feature", "description": "## Requirements\n\n- Feature A\n- Feature B"}
•	Get Issue: {"issue_key": "PROJ-123", "fields": "summary,status,assignee", "comment_limit": 5, "include": "remote_links,transitions"}
